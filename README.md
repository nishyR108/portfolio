# Nishant Thakur — Single Page Portfolio

A single-page React + TypeScript portfolio rebuilt from the original multi-page project.

## Highlights

- One continuous page: Home, About, Projects, Certifications and Contact.
- Framer Motion animations for section reveals, staggered content, hover effects and modals.
- Project case studies open in an animated modal instead of separate routes.
- Certificate previews open in an animated modal.
- Sticky responsive navigation with active section tracking.
- Existing profile image, resume, certificates and project case-study content are preserved.

## Run locally

```bash
npm install
npm run dev
```

The project uses `framer-motion`. If you are using the existing lockfile and npm asks to update it, run:

```bash
npm install framer-motion
```

Then:

```bash
npm run build
```
